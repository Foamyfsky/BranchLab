# `@branchlab/reference-world`

## Ownership

Owns future tiny fictional fixtures used to test determinism, conservation, branch isolation, and
early UI workflows independently of the large TfNSW feed.

## Forbidden dependencies

- No raw TfNSW data or real station names in reference fixtures.
- No React, Next.js, MapLibre, deck.gl, or app UI code.
- No OpenAI SDK or generated scenario content.
- No large binary fixtures.
