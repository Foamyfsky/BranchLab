# `@branchlab/experiment-analysis`

## Ownership

Owns future paired Monte Carlo analysis, common-random-number seed schedules, effect distributions,
uncertainty intervals, first/largest divergence summaries, and causal propagation records.

## Forbidden dependencies

- No React, Next.js, MapLibre, deck.gl, or HUD components.
- No OpenAI SDK or explanatory prose generation.
- No raw GTFS reads.
- No mutation of simulation histories; consume recorded experiment outputs.
