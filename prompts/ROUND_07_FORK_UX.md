# Round 07 — Intervention, Fork, and Lens UX

Build the complete non-AI interaction.

## Build

- contextual controls for service, capacity, station throughput, and closure/guidance;
- typed intervention preview and confirmation;
- branch lanes and selection;
- split-reality synchronised playback;
- branch metrics and trade-off inspector;
- Math Lens from recorded update terms;
- Causal Lens from typed simulator events;
- uncertainty summary;
- challenge budget and success conditions;
- signature fork animation that does not mutate simulation truth;
- export/import UI.

## Gate

A first-time tester can complete pause → intervene → fork → compare without instructions.
